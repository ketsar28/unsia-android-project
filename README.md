# Unsia Android Project

Project ini adalah kumpulan tugas mata kuliah Pemrograman Bergerak (Android) di Universitas Siber Asia.

## 📌 Update Terbaru: Pertemuan 4 (Validation, Dashboard & Implicit Intent)
Pada pertemuan ini, fokus utama adalah penguatan logika aplikasi melalui validasi input, pembuatan Dashboard profesional, dan penggunaan Implicit Intent.

### Fitur Baru & Perubahan:
- **Dynamic Display Name**: User dapat memasukkan nama lengkap saat login yang kemudian ditampilkan secara dinamis di Dashboard.
- **Login Validation**: 
  - Validasi input kosong (Nama, Username, Password).
  - Validasi kredensial (Admin: `admin/admin123`, User: `user/user123`).
  - Toast notification untuk umpan balik sukses/gagal.
- **Dashboard UI Professional**:
  - Header modern dengan sapaan nama dinamis.
  - Custom Bottom Navigation Bar (Home, Search, Profile).
- **Implicit Intent**: Tombol "Search" di navigasi bawah mengarahkan user ke browser eksternal (Google).
- **Resource Strings with Placeholders**: Menggunakan `%s` di `strings.xml` untuk efisiensi pengiriman data teks.

## 📌 Pertemuan 3 (Activity & Intent)
- **Navigasi Antar Halaman**: Menggunakan `Explicit Intent`.
- **Passing Data**: Mengirim data Nama, Umur, dan Nilai antar activity.
- **UI Modern**: Implementasi `MaterialCardView`.

## 🛠️ Teknologi
- **Language**: Java
- **UI Framework**: Material Components for Android
- **Satuan Ukuran**: `dp` (layout) dan `sp` (teks)
