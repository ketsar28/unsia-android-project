# Unsia Android Project - Pertemuan 2

Project ini adalah tugas mata kuliah Pemrograman Bergerak (Android) Pertemuan 2 di Universitas Siber Asia. Project ini mengimplementasikan form login modern menggunakan berbagai komponen UI Android.

## 🚀 Fitur
- **Layout Responsive**: Menggunakan `LinearLayout` di dalam `ScrollView`.
- **Custom Vector Asset**: Ikon profil modern menggunakan Vector Drawable (`.xml`).
- **Input Components**: 
  - `EditText` untuk Username dan Password.
  - `RadioGroup` & `RadioButton` untuk pemilihan Role (Admin/User).
  - `CheckBox` untuk berbagai opsi tambahan (Remember Me, Biometric, dll).
- **Edge-to-Edge**: Mendukung tampilan layar penuh modern.

## 🛠️ Teknologi & Satuan
- **Language**: Java / XML
- **Satuan Ukuran**: 
  - `dp` (Density-independent Pixels) untuk layout dan margin.
  - `sp` (Scale-independent Pixels) untuk ukuran teks.
- **Gradle**: Menggunakan Gradle Wrapper untuk konsistensi build.

## 📸 Tampilan Form
Form login mencakup:
1. Header "FORM LOGIN"
2. Ikon Profil (Vector)
3. Input Username & Password
4. Pilihan Role (Admin/User)
5. Checklist Opsi Tambahan
6. Tombol Login & Register

## ⚙️ Cara Menjalankan
1. Clone repository ini.
2. Buka di Android Studio.
3. Jalankan melalui emulator atau device fisik.
4. Atau gunakan terminal:
   ```bash
   ./gradlew assembleDebug
   ```
